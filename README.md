This entry is an editorial infographic for make.fun's **news-image-20261118** competition, summing up Wednesday, 18 November 2026. It uses six compact story panels about APEC trade talks, fighting in Gaza and the Gulf, COP31 climate demands, river pollution in Thailand, and Myanmar's dispute with ASEAN.

## Run locally

Use Python 3.13. The program uses only the standard library and draws the image itself.

```sh
python3 -P -s main.py
```

The program writes `entry.png` to the directory named by `MAKEFUN_OUTPUT_DIR`; if that variable is unset, it writes to `/output`. The output is a deterministic 1024 × 1024 PNG.
